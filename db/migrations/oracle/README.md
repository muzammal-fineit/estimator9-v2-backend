# Oracle migrations

Empty, and blocked further than MySQL is — see `db/README.md`.

`sqlx` has no Oracle driver at all, so this folder cannot be used until the
application's data access is changed. Translating the DDL is the small part:
`bigserial` → `GENERATED BY DEFAULT AS IDENTITY`, `timestamptz` → `TIMESTAMP WITH TIME
ZONE`, `jsonb` → `CLOB CHECK (... IS JSON)`, `text` → `VARCHAR2`/`CLOB`,
`ON CONFLICT DO NOTHING` → `MERGE`.
